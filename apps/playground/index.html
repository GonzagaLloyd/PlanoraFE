Planora widget playground

Each page installs the widget a different way. Mock API and ops page: localhost:8787.

  • Plain HTML — one <script> tag, the way any stack installs it (Laravel, Django, WordPress, Rails…)
  • React app — @planora/widget-react, with login/logout to test identify
  • Hostile CSS — aggressive global styles and z-index wars; the widget must look identical
  • Public mode — anonymous visitors, different branding, bubble on the left
